## 二、如何和 AI 说——TRI 专属 Prompt 模板库

这是你问的第二个问题的核心。优秀的 AI 协作不在于每次重新解释背景，而在于**用结构化的 Prompt 让 AI 在你的分析框架内工作**。

以下是六套经过优化的 Prompt 模板，可以直接复制使用：

---

### 🔍 Prompt 1：季报快速解析

```
你是我的TRI汤森路透投资分析助手。

【背景】我持有TRI，核心投资逻辑是：
- Big Three（法律/企业/税务会计）有机增速维持9%+
- AI产品（CoCounsel）成为增长加速器而非被颠覆
- EBITDA利润率每年扩张~100bps
- FCF年化~$2B+，支撑持续分红和回购

【任务】请分析刚发布的[年份Q*]财报，重点回答：
1. Big Three三个板块分别的有机增速是多少？达到管理层指引了吗？
2. 调整后EBITDA利润率是多少？是否在按计划扩张？
3. AI相关KPI（CoCounsel用户数、AI占ACV比例）有什么更新？
4. 管理层对下一季度/全年的Guidance是否调整？
5. 有没有出现我需要特别关注的风险信号（留存率下滑、政府客户问题、竞争压力）？

【输出格式】
- 每个问题直接给结论，再给数据
- 最后给出一句话：这份财报是否改变了我的投资逻辑？
```

---

### 📰 Prompt 2：单条新闻影响评估

```
我正在跟踪TRI汤森路透的投资。

【我的TRI投资逻辑核心】
- 护城河：Westlaw150年数据+1600名律师编辑的无形资产；税务/法律软件的高转换成本
- 增长：Big Three 9%+有机增速+AI产品渗透
- 真正的风险：AI进入法律"判例研究+权威引用"核心功能（而非合同审查等外围任务）

【任务】请分析以下这条新闻对TRI的影响：

[粘贴新闻标题和内容]

请按以下维度回答：
1. 这条新闻影响TRI的哪个变量？（护城河/增长引擎/财务健康/管理层/外部环境）
2. 影响方向（正面/负面/中性）和量级（重大/中等/轻微）
3. 是否改变了我的核心投资逻辑？为什么？
4. 我应该采取什么行动？（加仓/持有/减仓/继续观察）
```

---

### ⚔️ Prompt 3：竞争对手动态追踪

```
我在跟踪TRI汤森路透的竞争格局。TRI的主要竞争威胁来自：
- 直接竞争：RELX（LexisNexis）、Wolters Kluwer
- AI原生挑战者：Harvey AI（法律）、Clio（法律实践管理）
- 颠覆性威胁：Anthropic/OpenAI直接进入法律/税务专业市场

【任务】请帮我搜索并分析以下竞争对手的最新动态：
[指定竞争对手名称]

重点关注：
1. 他们是否在攻击TRI的核心护城河（法律研究数据库、税务申报软件）？
2. 他们的融资/估值/ARR数据有什么变化？
3. 他们的产品是在"绕过"TRI（外围功能）还是在"正面竞争"（核心功能）？
4. 这对TRI的Big Three增速预测有什么影响？

请给出结论：竞争格局是在恶化、维持还是改善？
```

---

### 💰 Prompt 4：估值动态追踪

```
【背景】我对TRI的估值框架：
- 2025年业主盈余（Owner's Earnings）≈ $1,974M
- 当前增速：8%有机增长，利润率每年扩张
- 基准内在价值（9%折现率）≈ $117/股
- 理想买点（25%安全边际）≈ $87-90/股
- 当前价格：$[当前价格]/股

【任务】
1. 基于最新财报数据，帮我更新业主盈余计算（净利润+D&A-维持性Capex-SBC）
2. 如果增速从8%上调到[X%]或下调到[Y%]，内在价值会变为多少？
3. 当前股价对应的隐含增速是多少？市场预期合理吗？
4. 相比于RELX和Wolters Kluwer，TRI当前的相对估值如何？

请用具体数字回答，不要只给定性描述。
```

### 🧠 Prompt 5：年度投资逻辑全面复核

```
请帮我对TRI汤森路透做一次年度投资逻辑复核。

【我的原始投资逻辑（建立于2026年初）】
1. 护城河：窄护城河（Morningstar评级），来源是无形资产（Westlaw数据库）+转换成本（税务/法律软件嵌入客户工作流）
2. 成长：Big Three 9%+有机增长，AI产品（CoCounsel）加速渗透，利润率年扩张100bps
3. 估值：基准内在价值$117，理想买点$87-90，当前价格$104.83
4. 核心风险：AI颠覆法律研究核心功能（目前评估概率5%）

【任务】
请搜索最新信息，逐一检验这5个核心假设是否依然成立：
- Big Three增速是否维持在9%+？
- CoCounsel增长轨迹是否符合预期？
- 利润率扩张是否在按计划推进？
- AI对Westlaw核心功能的威胁是否有实质性升级？
- 管理层资本配置是否依然优秀？

最终给出：投资逻辑是否强化/维持/弱化？是否需要调整仓位？
```

### 🌐 Prompt 6：每日新闻快速筛选

```
请帮我搜索过去24-48小时内，与以下关键词相关的重要新闻，并筛选出与我的TRI投资逻辑相关的信息：

【关键词清单】
公司层面：Thomson Reuters, TRI, Westlaw, CoCounsel, UltraTax CS, Steve Hasker
竞争层面：Harvey AI, LexisNexis, Wolters Kluwer, legal AI
行业层面：legal technology, tax software, AI disruption legal, legaltech funding
宏观层面：US legal market, government spending legal, bar association AI

【筛选标准】
只报告满足以下任一条件的新闻：
- 直接影响TRI的护城河（法律研究核心功能被攻击）
- 直接影响Big Three的有机增速预期
- 竞争对手重大融资/产品发布（Harvey ARR突破/Claude进入法律研究）
- 管理层重大人事变动或资本配置决策
- 监管政策对法律/税务AI的重大影响

无关噪音（如：普通季报解读、一般性AI新闻、股价波动评论）请过滤掉。

输出格式：每条新闻[标题+一句话影响评估+影响方向（正面/负面/中性）]
```

## 三、如何构建系统性的 TRI 跟踪工作流

基于这六套 Prompt，建议以下节奏：

|频率|动作|用哪个 Prompt|
|---|---|---|
|**每日**|5 分钟新闻扫描|Prompt 6|
|**重大新闻出现时**|单条新闻影响评估|Prompt 2|
|**竞争对手有动态时**|竞争格局分析|Prompt 3|
|**每季报（约 3 个月一次）**|季报解析 + 估值更新|Prompt 1 + Prompt 4|
|**每年一次**|投资逻辑完整复核|Prompt 5|

---

## 四、一个关键原则：给 AI 的"记忆锚点"

每次新对话开始时，AI 没有上下文记忆。养成这个习惯：**在每次 Prompt 开头加入简短的背景摘要**。

推荐固定的"TRI 背景锚点"：

```
【我的TRI投资背景（每次对话请先读这段）】
- 公司：汤森路透（TRI），Nasdaq上市，法律/税务/企业信息服务订阅公司
- 投资逻辑核心：Big Three有机增速9%+；AI产品（CoCounsel）护城河加宽；FCF ~$2B/年，年增8%
- 护城河来源：Westlaw 150年数据库+1600名律师编辑（无形资产）；税务软件嵌入工作流（转换成本）
- 核心风险：通用AI进入法律研究核心功能；Harvey AI规模化
- 估值基准：2025年OE≈$1.97B；基准内在价值$117；理想买点$87-90
- 当前状态：持有/关注中，股价约$[更新]
```

把这段文字保存好，每次和 AI 开始新对话时粘贴在最前面。这样 AI 就能在你已有的分析框架内工作，而不是每次从零开始。

---

这套体系将我们之前四次深度分析的成果转化成了可持续运作的追踪系统。最关键的是最后那个"投资逻辑核心假设清单"——只要这五个假设都还成立，短期股价波动就不需要担心；一旦有任何一个出现裂缝，才是真正需要重新思考的时候。
