# **原则一，污染隔离**

**第一层：为什么要做信息隔离，防止污染？**

因为“取信息”和“做分析”根本不是同一种任务。前者要尽量保留原始出处、时间、上下文；后者一定会做筛选、压缩、归因和推演。问题在于，LLM 的底层不是“先查库、再思考”的两套独立系统，而是同一个连续生成系统：它一直在根据上下文，生成“下一个最可能的 token”。这意味着，只要任务里包含“分析”，模型在整理信息时就很难完全中立，往往会提前概括、排序、弱化或强调某些材料。于是事实层就被解释层污染了。

**第二层：在一个聊天里让它分步骤做可以吗？**

还是不行，这不够硬？（理论上现在高级模型越来越强，但幻觉不可消除）

因为这通常只是“排版分层”，不是“认知隔离”。你让它在同一次回答里先列信息、再做分析，看起来分成了两步，但模型从一开始就知道后面要得出结论，所以前面的信息提取，已经会被后面的目标反向牵引。也就是说，污染不是发生在第二段，而是第一段就开始了。真正更稳的做法是分两轮：第一轮只取证，第二轮只分析。这样你拿到的才是干净材料，而不是模型为了结论预处理过的材料。

必须防止 AI模型 **串供** ，先丢飞刀再画靶子

所以必须强行隔离，系统从头到尾只输出**纯事实，严禁任何主观、分析、预测、观点（连“可能”“预计”“风险”这种词都不准出现）。**就要这么狠，一旦混进分析，事实就容易被扭曲放大幻觉。想分析？我通常都是单独，开一个project，有一条专门的系统去做，通常我会用4大模（Chatgpt，Grok，Claude，Gemini）跨模型交叉校验，这已经是主流的趋势，最好都用高级推理模型，这很烧钱但必须。投资追求高置信，逻辑干净硬核，这点成本还好。

﻿

﻿ **污染隔离为第一原则，高置信度的关键，** 绝对不推荐把材料层和观点层搅在一起，伤害很大。

# **原则二，增量更新，效率爆表**

这是我降低阅读负担的操作，AI输出信息是快，但肉眼阅读速度没有提升，所以我设计这个增量更新，源于软件开发，增量打包发版本，效率及高，而且增量更新这种工程术语，语意清晰赚足钱呢，作为ai指令异常友好。在单一对话长上下文的过程中不易脱靶。

原理很简单，第一次查询时间，让Grok给你新闻后，要求结尾必加一个**时间戳**。并且强制要求，增量更新，它就只吐出上次时间戳之后的新事实，绝不重复旧内容。为什么非要时间戳？因为新闻事件滚雪球式发展，每次AI都会冲头所起，混淆时间线，上下文一长就乱套，手动翻历史超烦。AI输出内容是效率高了，人的研究阅读效率没有提升啊，减低阅读负担。时间戳像书签，自动锚定“上次看到哪儿”，以后更新永远从那儿接上，小小的操作效率直接拉满，用了就回不去了。即使聊几百条，规则这么清晰，Grok 也不会崩。有了时间戳校验，一般Grok，只要强调要新闻，实时信息基本不会给过期信息，但用Gemini就得防它给你变质内容。

﻿

# **原则三，指令定义：**

我一般定义太多花里胡哨的指令，确保简单高效，低摩擦力为第一原则。

中文指令，触发关键词我设计必须放在消息最开头，句首才生效，放在句子中间不会误触发，或者用/加英文，为什么不是/+中文 做指令，全角/半角混合输入容易出错，这是我的防手滑神器，尤其是高频使用，谁用谁知道，我的独家设计。

我的3个常用指令：

**更新** **或** **/update** → 增量新进展（最常用，随时点一下就出新东西） **复盘** **或** **/recap** → 完整时间线（从头到尾的关键节点，按时间顺序整理） **全景** **或** **/snapshot** → 当前最新现状快照（不带历史过程，快速看一眼现在啥情况） **重置** **或** **/reset** → 从现在重新开始记时间戳（适合一个阶段结束，想清零重来）

# 原则四，消息源约束

消息源再一波约束，通常个家AI都会选交友影响力的消息源。但消息源我还是做了一些约束。

**禁用所有中文媒体，社区自媒体平台（噪音最大、翻译偏差），除非需要查国内信息动态。**

消息源：（通常不强制，但选择优先级，做分散，不强制是因为有时候会有某个独家消息源的重头消息。）做分散也是保持交叉校验和以免偏颇。所有的观点评类内容必须被排除了。

英文主流：Reuters、BBC、AP、Al Jazeera + 官方声明（IDF、IRNA等）。金融数据用 Yahoo Finance、Polygon、CNBC、Bloomberg 公开部分等。Bloomberg终端虽然贵，但免费公开新闻还是可以看看。

本质上还是二次做边界约束，第一性原理：本质上你搜索内容，条件越多（有效），得到的结果月匹配。

**亮点就这几刀：** **纯增量** **+** **时间戳滚动，彻底解决“刷新闻刷到重复、翻历史翻到吐”的痛点 消息源强制禁用中文区（噪音/偏差太大），优先国际主流英文源** **+** **官方声明** **+** **免费金融数据，靠谱度高 污染隔离** **+** **边界硬限定，事实和观点永不混淆 指令句首触发，零误操作，操作成本低到爆**
